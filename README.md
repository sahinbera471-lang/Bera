# Bera – Claude Skills

Skills zum Teilen mit anderen Claude-Nutzern.

| Skill | Zweck |
|---|---|
| [`lohn-st`](skills/lohn-st/SKILL.md) | **Lohn ST** – entfernt aus einer Excel-Monatsübersicht (Stundenzettel) die Tageszeilen und zeigt nur die Stunden je Zuschlagsart (Nacht, Sonntag, Feiertag, Überstunden …). |

## Installation

- **claude.ai / Claude-App:** `dist/lohn-st.zip` herunterladen → *Einstellungen → Funktionen (Capabilities) → Skills → Skill hochladen*.
- **Claude Code:** Ordner `skills/lohn-st` nach `~/.claude/skills/` (persönlich) oder `.claude/skills/` (Projekt) kopieren.

Danach einfach die Excel-Datei hochladen und „Lohn ST“ sagen.
