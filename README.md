# Bera – Claude Skills

Skills zum Teilen mit anderen Claude-Nutzern.

| Skill | Zweck |
|---|---|
| [`lohn-st`](skills/lohn-st/SKILL.md) | **Lohn ST**: blendet in der Excel-Monatsübersicht die Übersicht der einzelnen Monate/Tage aus, sodass nur der Teil für den Steuerberater sichtbar ist (Urlaub/Konten, Monatsabrechnung, Weitere Angaben). Nichts wird gelöscht oder verändert. |

## Installation

- **claude.ai / Claude-App:** `dist/lohn-st.zip` herunterladen, dann *Einstellungen → Funktionen (Capabilities)*. Dort „Code-Ausführung und Dateierstellung“ einschalten und unter *Skills* „Skill hochladen“ wählen.
- **Claude Code:** Ordner `skills/lohn-st` nach `~/.claude/skills/` (persönlich) oder `.claude/skills/` (Projekt) kopieren.

Danach die Excel-Datei hochladen und „Lohn ST“ schreiben.
